# User Rule: Always Git Commit

The user has explicitly requested: **"always do git commit after every changes"**.

## Instructions
1. After completing any meaningful modification, file creation, or code generation task, you MUST automatically run `git add .` and `git commit -m "..."`.
2. Do this without asking for permission unless there is a specific risk (e.g., massive accidental data loss, which falls under other rules).
3. Ensure the commit message is descriptive of the changes just made.
